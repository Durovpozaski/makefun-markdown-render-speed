# Make Markdown rendering faster

[![Make Markdown rendering faster](https://make.fun/badge/markdown-render-speed-02.svg)](https://make.fun/bounty/markdown-render-speed-02)
[![Rank](https://make.fun/badge/markdown-render-speed-02/Durovpozaski/makefun-markdown-render-speed/rank.svg)](https://make.fun/bounty/markdown-render-speed-02)
[![Reward](https://make.fun/badge/markdown-render-speed-02/Durovpozaski/makefun-markdown-render-speed/reward.svg)](https://make.fun/bounty/markdown-render-speed-02)

A dependency-free JavaScript module, `parse.js`, whose `parse(markdown)` returns
exactly the HTML that marked 18.1.3 renders with its default options
(GitHub Flavored Markdown on) — but faster. Plus `main.ts`, the program that
renders every case with it.

Entry for the [make.fun bounty "Make Markdown rendering faster"](https://make.fun/bounty/markdown-render-speed-02).
